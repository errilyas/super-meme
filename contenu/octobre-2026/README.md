## 2. Reel « Pourquoi 249 DH ? » (réponse aux commentaires sur le prix)

Basé sur ce que dit le site : testeurs officiels, même jus, sans le coffret.
Format : face caméra, 25 à 35 s, sous-titres en darija. Le flacon testeur et
sa boîte blanche « Tester » en main.

| Plan | Ce qu'on voit | Texte dit (darija) | Sous-titre à l'écran |
|---|---|---|---|
| 0-3 s | Gros plan sur un commentaire « 249 dh ? rah dayra 1350 » | بزاف ديال الناس كيسولونا: علاش 249 درهم؟ | علاش 249 درهم؟ 🤔 |
| 3-10 s | La boîte blanche « Tester » à côté d'un coffret de boutique | هادا تيستور. القنينة اللي كتصاوبها الماركة باش الناس يشمو فالبوتيك | تيستور = قنينة الماركة |
| 10-17 s | On ouvre la boîte, flacon plein, bouchon | نفس العطر، نفس التركيز، نفس الحجم. الفرق غير فالعلبة | نفس العطر · بلا العلبة |
| 17-24 s | Zoom sur le code de lot sous le flacon, puis écran CheckFresh | شوف الكود اللي تحت القنينة، دخلو ف CheckFresh وتعرف تاريخ الصنع | تأكد براسك من الكود |
| 24-32 s | Le livreur tend le colis, le client paie en main propre | وما كتخلص حتى يوصلك الكوليس لعندك، فيدك | الخلاص عند الاستلام |

**Légende**

```
« 249 DH, c'est un faux ? » On nous le demande souvent, alors voilà la réponse. Un testeur, c'est le flacon que la marque fabrique pour ses boutiques : même jus, même volume, sans le coffret. Vérifie le code de lot toi-même, et tu ne paies qu'une fois le colis en main 📦
```
